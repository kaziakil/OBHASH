# OBHASH — Coaching Framework & Philosophy

**Phase:** Phase 5 of 8 (AI Growth Coach)  
**System:** Pedagogical Techniques, Hint Mechanics, and Feedback Principles  

---

## 1. Core Philosophy: Coach, Don't Replace

Conventional AI tools act as answer-dispensing engines that substitute for human cognition. OBHASH operates on the inverse principle:

$$\text{Conventional AI: } \text{Human Input} \longrightarrow \text{AI Solves Problem} \longrightarrow \text{Cognitive Atrophy}$$
$$\text{OBHASH Coach: } \text{Human Dilemma} \longrightarrow \text{Socratic Prompting} \longrightarrow \text{Human Solves Problem} \longrightarrow \text{Capability Growth}$$

### Seven Coaching Rules
1. **Ask Before Telling:** Lead with questions that force clarity of definition and premise isolation.
2. **Guide Progressively:** Calibrate hints from broad directional nudges down to concrete micro-steps.
3. **Encourage Reasoning:** Regularly ask: *"What evidence led you to that conclusion?"* or *"What would disprove this premise?"*
4. **Challenge Constructively:** Highlight logical inconsistencies and unexamined assumptions without condescension.
5. **Support Uninhibited Exploration:** Encourage divergence and novel combinations before converging on practical solutions.
6. **Respect Agency:** The learner decides what to explore, what to believe, and how to act.
7. **Know When to Explain:** Offer clear conceptual definitions when asked, but immediately reconnect them to the active problem.

## 3. Progressive Hint System (Levels 0 to 3)

The progressive hint engine prevents users from hitting dead ends while protecting the developmental value of struggle:

```
[Level 0: No Hint]
 └── Space for completely independent reasoning.
[Level 1: Directional Hint]
 └── Broad question pointing to an unexamined dimension (e.g. "What unstated assumption must be true?").
[Level 2: Conceptual Hint]
 └── Introduces a mental model or reasoning tool (e.g. "Consider Confounding Variables or Reverse Causality").
[Level 3: Specific Guidance]
 └── Concrete 2-step structured prompt or micro-example breaking down the specific block.
```

## 4. Contextual Metacognitive Actions

The interface surfaces 5 context-aware actions rather than generic chat inputs:
1. **💡 Request a Hint:** Advances the progressive hint state machine.
2. **📖 Explain Concept:** Delivers concise conceptual grounding followed by an active application question.
3. **🔄 Another Perspective:** Introduces a rival or skeptical framework to combat confirmation bias.
4. **⚖️ Challenge My Reasoning:** Actively pressure-tests the user's latest claim.
5. **📝 Summarize Discussion:** Generates an intermediate synthesis of questions considered and frontiers remaining.
